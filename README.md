# BNCT_Monitoring_Project
This project leads to the development of a prototype device for monitoring in BNCT cancer therapy. Project is conducted by a research group at the Faculty of Physics, Astronomy and Applied Computer Science of Jagiellonian University.

This project is funded by the state budget through a grant awarded by the Minister of Science and Higher Education under the Programme ”Student Scientific Associations Create Innovations.”
· Project title: Construction of a Prototype Device for Monitoring Boron Neutron Therapy
· Agreement number: SKN/SP/658625/2026
· Project duration: 19 March 2026 - 19 March 2027
· Grant amount: PLN 69,928.33
· Total project value: PLN 69,928.33
